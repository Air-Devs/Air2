# Air2 UI 设计规范

> **设计依据**：Material Design 3 规范
> **不参考任何现有启动器的具体界面**。ZL2 仅作为「iOS 上哪些交互决策可行」的验证参考，
> 不作为视觉蓝本。

---

## 一、设计定位

Air2 是 **iOS 横屏**的 Minecraft Java 版启动器。

**为什么横屏**：Java 版本身就是横屏游戏。启动器横屏后，点「启动游戏」到游戏画面
出现之间不会有方向切换的黑屏与旋转动画，体验是连续的。这是功能性理由，
不是为了像谁。

**横屏带来的设计机会**：宽度充裕，可以左右分区。左侧留给「个性化」
（用户自己的壁纸），右侧是「功能性操作区」。这是 iOS 上多数专业工具类 App
的常见做法（如 Final Cut、Logic 的横屏布局思路）。

## 三、颜色系统

严格按 **Material Design 3 的 ColorScheme 语义**建模。

### 3.1 语义字段（视图层只用这些，不直接写色值）

| 分组 | 字段 | 用途 |
|---|---|---|
| 主色 | `primary` / `onPrimary` | 填充按钮、强调操作 |
| | `primaryContainer` / `onPrimaryContainer` | 次级填充、选中态背景 |
| 次要 | `secondary` / `onSecondary` | 次要操作 |
| | `secondaryContainer` / `onSecondaryContainer` | 标签、Chip 底色 |
| 表面 | `surface` | 页面最底 |
| | `surfaceContainerLowest` → `Highest` | 五档层级，卡片按深度选用 |
| | `onSurface` / `onSurfaceVariant` | 主文字 / 次要文字 |
| 描边 | `outline` / `outlineVariant` | 强描边 / 弱分割线 |
| 语义 | `error` / `success` / 各自 container | 状态反馈 |

**关键原则**：同一套语义字段在亮色与暗色下取不同值，视图层不判断模式。

### 3.2 层级与卡片对应

| 卡片 | 使用字段 | 说明 |
|---|---|---|
| 页面背景 | `surface` | 最底 |
| 普通卡片 | `surfaceContainer` | 默认 |
| 悬浮/高亮卡片 | `surfaceContainerHigh` | 需要突出时 |
| 内嵌条目 | `surfaceContainerLowest`(亮) / `Highest`(暗) | 与卡片形成对比 |

### 3.3 内置主题

不照搬 ZL2 的色板，重新设计：

| 主题 | 亮色 primary | 暗色 primary | 气质 |
|---|---|---|---|
| **Embermire** 烈焰红棕 | `#A63A17` | `#FFB59F` | 暖、有力，默认 |
| **Glacier** 冰川蓝 | `#00658B` | `#7FD0F5` | 冷、克制 |
| **VerdantDawn** 青野绿 | `#2C6B36` | `#8ED88E` | 自然、贴合主题 |
| **VelvetRose** 绛紫玫瑰 | `#7A3D58` | `#F9B2D2` | 柔和、低对比 |
| **UrbanAsh** 都市灰 | `#5E5E5F` | `#C7C6C6` | 中性、专注 |
| **Dynamic** 动态 | 从壁纸提取 | | 个性化 |

每套都提供完整的亮/暗两套 `A2ColorScheme`。

## 四、自定义背景

这是个性化最主要的部分。

**支持的形式**：
1. **用户图片** —— 从相册选择或文件导入
2. **主题渐变** —— 内置主题的渐变色 + 径向光斑
3. **纯色** —— 取当前主题的主色

**图片处理规则**：

| 处理项 | 规则 |
|---|---|
| 填充方式 | `scaleAspectFill`，居中裁切 |
| 模糊 | 可选，0~100 强度 |
| 暗色遮罩 | 暗色模式下叠加 0.28 黑色，保证右侧文字可读 |
| 右侧渐隐 | 图片右侧 35% 加一层向操作栏方向的渐变遮罩，避免卡片与背景对比不足 |

最后一条很关键：用户可能选一张花哨的图，直接放会让右侧卡片糊在一起。
加一层渐隐（图片色 → 半透明黑）能让操作区始终有稳定的对比度。

## 五、动效系统

| 场景 | 效果 | 时长 / 参数 |
|---|---|---|
| 页面推入 | 缩放淡入（0.96 → 1） | 0.38s spring damping 0.78 |
| 页面返回 | 缩放淡出 + 下层回弹 | 0.34s spring |
| 卡片入场 | 从下方 16pt 淡入，依次延迟 35ms | 0.42s spring damping 0.82 |
| 按压缩放 | scale 0.97 | 0.18s spring |
| 主按钮点击 | scale 0.96 + 触觉反馈 | 0.16s spring |
| 主题切换 | 全界面颜色交叉淡入 | 0.45s ease-in-out |
| 背景切换 | 交叉淡入 + 轻微缩放 | 0.6s ease-out |
| 进度推进 | 弹性跟随 | 0.38s damping 0.9 |
| 抽屉展开 | 弹簧 + 高度 | 0.4s damping 0.75 |
| 开关切换 | 颜色过渡 | 0.2s |
| 列表项插入/删除 | 高度 + 淡入淡出 | 0.3s |

**统一原则**：
- 所有位移用 `UIViewPropertyAnimator` + `UISpringTimingParameters`
- 不用 `ease-in-out`（iOS 上手感发木）
- 触觉反馈分级：轻（选择）→ `UISelectionFeedbackGenerator`，
  中（按钮）→ `UIImpactFeedbackGenerator(Medium)`，
  成功/失败 → `UINotificationFeedbackGenerator`
